## 为什么搭建这个博客

作为一名计算机科学专业的学生，我一直想有一个属于自己的、可以长期沉淀知识的地方。在对比了各种方案后，我选择了 **Hugo** —— 一个速度极快、支持 Markdown 写稿的静态站点生成器。

## 我会在这里写什么

- **课程笔记**：数据结构、操作系统、计算机网络等核心课程
- **考研数学一**：知识点梳理、错题总结、真题讲解
- **编程实践**：踩坑记录、项目复盘、实用技巧
- **杂谈**：读书、写作、生活感悟

## 关于这个站点

- 技术栈：Hugo + Stack 主题
- 特点：卡片式布局、支持深色模式、内置搜索、自动归档
- 本地预览：`D:\hugo\hugo.exe server -D`（在 `D:\hugo\blog` 目录下运行）

## 接下来

我会陆续把之前整理的学习笔记迁移上来，也会每周保持更新。欢迎常来看看，也欢迎通过 GitHub 或邮箱和我交流。

> 千里之行，始于足下。
